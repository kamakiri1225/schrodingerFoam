# 07 ダークソリトンの崩壊から2次元量子乱流へ（schrodingerFoam）

> シリーズ第7回。前回（06 走る渦対）の先、ダークソリトンが量子渦へ崩壊して
> 2次元量子乱流になる様子を、エネルギースペクトル・カスケード・渦数・Helmholtz
> 分解で定量化する。

Gross–Pitaevskii 方程式 `i∂ψ/∂t = -D∇²ψ + (Vext + g|ψ|²)ψ`（`D=0.5, g=1`）を
`schrodingerFoam` で解き、**ダークソリトンの崩壊から2次元量子乱流を生成**し、その
統計を後処理する。参考：Numasato–Tsubota–L'vov, *Direct Energy Cascade in 2D
Compressible Quantum Turbulence*, PRE **81**, 016303 (2010)（`docs/…Direct Energy
Cascade….pdf`）と 小林の学位論文（`docs/main.pdf`）。

## 1. 2つの乱流生成法

| | (A) ソリトン格子（一様系） | (B) 4凝縮体の干渉（トラップ系, 付録A） |
|---|---|---|
| ケース | `05_darkSoliton8_*`, `06_solitonLattice8x8_*` | `07_fourCondensate_trap_*` |
| 初期状態 | ソリトン解の積 `Ψ=Π tanh(x-xi)tanh(y-yi)` を虚時間で整える | トラップ＋**斥力十字** `V0(e^{-x²/d²}+e^{-y²/d²})` の基底状態＝4分離 |
| 引き金 | 白色ノイズ＋実時間発展 | **斥力を切る**→4凝縮体が中心へ落ち**干渉** |
| その後 | ダークソリトンが**スネーク不安定**で量子渦へ崩壊→乱流 | 干渉縞（=ダークソリトンの正方格子, 位相0/π交互）→崩壊→乱流 |
| 長所 | 一様で統計をとりやすい（論文の本編） | 実験に近い（`main.pdf` 図2.2–2.3, A.2） |

いずれも **2段階**：`imaginaryTime/`（基底状態を作る）→ `realTime/`（実時間発展）。
`muShift=μ` を引いて自明な全体位相 `e^{-iμt}` を止める（位相図がチカチカしない）。

### 数値上の注意
- (B) は斥力を切った直後に急峻な壁＋真空領域ができ、`deltaT=0.005` では発散
  （norm→10^50, SIGFPE）。**`deltaT=0.002`** に下げると norm 保存で安定。

## 2. 基本スケール（手計算）

一様バルク密度 `n0` に対し
- **癒し長** `ξ = √(D/(g n0))`。`n0=1` なら `ξ = √0.5 ≈ 0.707`。
- **ダークソリトン幅** `√2 ξ ≈ 1`（`tanh(x/√2ξ)`）。
- **音速** `c = √(g n0 / (2D)) · ... ` → 本無次元では `c = √(g n0)`（`=1`）。

`06` は格子間隔 6（ソリトンを `±3,±9,±15,±21` に配置）→ ソリトンスケールの波数
`k_sol = 2π/6 ≈ 1.05`。

### スネーク不安定の「崩壊波数」（オーダー見積り）
2次元でダークソリトン（1次元の厳密解）は**横方向の長波長ゆらぎに不安定**
（snake instability, Kuznetsov–Turitsyn 1988; 冷却原子では Muryshev 他）。黒ソリトンの
横波数 `q`（ソリトン線に沿う方向）の摂動 `∝ e^{iqy+γt}` は

  **不安定帯 `0 < q < q_c`, `q_c ξ = O(1)`（≈1/√2〜1）**, 最速成長 `q_* ≈ q_c/√2`。

→ 最も速く育つ横波長 `λ_* = 2π/q_* ≈ (数)×2π ξ`。`q_* ξ ≈ 0.5` とすると
`λ_* ≈ 4π ξ ≈ 12.6 ξ`。`ξ=0.707` で **`λ_* ≈ 9`**。

これがソリトンが割れて**量子渦対ができる間隔の目安**＝乱流の初期渦間隔で、
そこから非圧縮エネルギーが注入される。正確な係数は上記文献の線形安定性解析
（`docs/ボースアインシュタイン凝縮/ソリトン/`）で決まる。**観測値と比較**して裏取り
する（`qt_vortex_gif.py` の初期渦間隔、`qt_spectrum.py` のピーク波数）。

### 「どこにエネルギーを注入しているか」
本計算は**強制なしの減衰乱流**。連続的な注入はなく、**初期状態が全エネルギー源**。
- 論文：初期に**大スケール（低 k, `Δk≤|k|≤3Δk`, 式(9)）**へ注入 → 小へ順カスケード。
- 本ソリトン格子：初期エネルギーは**ソリトンスケール `k ≈ k_sol ≈ 1`〜`1/ξ`**に在る。
  スネーク不安定が `λ_*≈9`（`k≈0.7`）で渦を作り、そこから**非圧縮→圧縮（音）へ順カ
  スケード**。だから「注入スケール」は `k ~ 1`（ソリトン／初期渦間隔）と考えればよい。

## 3. 後処理（Helmholtz 分解とスペクトル）

`foamToVTK` 出力（`Psire, Psiim`）を Python で読み、Madelung 変換：
- 密度 `ρ=|ψ|²`、確率カレント `j = Ψre∇Ψim − Ψim∇Ψre`（`ħ/m=2D`）
- 流体速度 `v = 2D j/ρ`、**密度重み速度** `w = √ρ · v`（渦芯でも有界）
- **Helmholtz 分解** `w = w^i + w^c`（Fourier 空間, 論文式10d,e）
  - `w^i`：非圧縮（∇·=0）＝**回転＝量子渦**
  - `w^c`：圧縮（∇×=0）＝**音波**
- **運動エネルギースペクトル** `E^i(k), E^c(k)`（`∫E dk = E_kin`）

トラップ系は**内部だけで計算**する（`--rho-frac 0.3`）。外側の低密度ハロは位相が
ノイズで、`w` に偽の寄与＝**偽のスペクトル・偽の渦**を生むため、密度窓
`W=½(1+tanh((ρ-frac·peak)/…))` を `w` に掛けてから分解する。

## 4. エネルギーカスケードの向き（流束）

論文式(15)：**`ε^i(k,t) = −∫_{k_m}^{k} ∂E^i_kin(k',t)/∂t dk'`**
= 「k 以下（大スケール側）の非圧縮エネルギーが単位時間に減った量」。
- 慣性帯で `ε^i>0` → **順カスケード direct（大→小）**、`ε^i<0` → 逆（小→大）。
- 慣性帯のプラトー＝エネルギー流束 `ε`。`k^{-5/3}` の係数は **`A = C·ε^{2/3}`**（Kolmogorov）。

**重要（符号の取り違いに注意）**：`06` を全区間平均すると `ε^i<0`（逆に見える）が、
これは**初期のソリトン→渦形成の過渡**が支配するため。**時間窓を分ける**と：

| 区間 | `ε^i`（慣性帯平均） | 向き |
|---|---|---|
| 初期過渡 t=0–16 | −4.1 | 逆（見かけ） |
| **発達乱流 t=20–100** | **+3.19** | **順 direct ＝論文と一致** |

→ 発達した2次元量子乱流では**非圧縮エネルギーが小スケールへ順カスケードし、音波へ
変換**される（論文の主張と一致）。`qt_flux.py` は既定で最初の20%を過渡として除外。

## 5. 量子渦のカウントと減衰

- **数え方**：各プラケットの位相巻き数 = `±1`（`soliton_hist_ensamble.f90` と同一式を
  `detect_vortices_f90` に忠実移植、全時刻で従来法と `diff=0` を確認済み）。
- **偽渦**：`06` 初期は白色ノイズがソリトン節線（ρ≈0）上に格子スケールの偽 `±2π` 欠陥を
  多数作る（t=0 で 1452 本≈全部節線上）。これは本物の渦ではない。
- **偽渦除去＝擬渦度フィルタ**（`detect_vortices_f90(pseudo_frac)`）：
  擬渦度 `ω_ps = ∂xRe·∂yIm − ∂yRe·∂xIm = (∇Re×∇Im)_z` を使う。
  - 本物の渦：`ψ=0` の孤立点で `∇Re ⊥ ∇Im` が直交 → `|ω_ps|` 大（∼ n0/ξ²）。
  - ソリトン節線：Im≈0（∇Im がノイズ）→ `|ω_ps|` 小。
  `|ω_ps|` がバルク `n0/ξ²` の `pseudo_frac`（既定 0.03）倍未満のプラケットを捨てる。
  結果（`06`）：**t=0 が 1452→0（渦0本＝正しい）**、発達域（t≳24）は raw と一致。密着
  ダイポール消去／連結成分／ヘッセ／平滑化では分離できなかったが、擬渦度で綺麗に解決。
- **数え方の含意**：`06` の除去後 `N_v(t)` は「t=0≈0 →（スネーク不安定で）**渦生成のピーク**
  ∼250（t≈20）→ **`N_v ∝ t^{-1}` 減衰**」という**生成→減衰**を正しく描く（`vortex_decay.png`、
  `vortex_compare.gif`＝raw｜除去後）。生の巻き数だけでは初期の 1452 に隠れて見えない。
- **減衰則**：後期は **`N_v ∝ t^{-1}`**（渦・反渦の対消滅、常に net=0）。

## 8. 主な結果（07: 4凝縮体の干渉, トラップ, ±32, 256², ω=0.08, t=150）

付録Aの手順を実装（斥力十字で4分離 → 切って干渉）。ノイズは 10⁻³ を1回だけ。

- **干渉の再現**：t≈20 で4凝縮体が中心衝突し、密度に**十字状のダークソリトン**が現れる
  （図2.2/2.3）。位相は 0/π 交互。→ ソリトンが崩壊して量子渦へ。
- **渦生成はバースト的**：`N_v` は t=18 で**ピーク16本**、その後トラップ振動（周期
  2π/ω≈78）に伴い増減を繰り返し（t=63 で12本など）、**t≈105 以降ほぼ0**へ減衰。
  06 のような綺麗な `t^{-1}` ではなく、**弱い・非定常**な減衰乱流。
- **弱い順カスケード**：慣性帯平均 `ε^i≈+0.15`（direct だが 06 の +3.2 より桁小さい）。
- **偽渦は元々ほぼ無い**：raw と 擬渦度除去後が全時刻で一致（ソリトン線にノイズを乗せ
  ないため）。→ 偽渦除去は 06 固有の問題だったと裏づけ。マスクは `--rho-frac 0.05`
  （0.3 は縁の渦まで消す。トラップ外ハロは数千の偽巻き→マスク必須）。
- **なぜ弱いか**：系が小さく（±32＝64ξ、凝縮体半径∼12）、トラップ振動が支配的。
  **論文の方針と一致**：main.pdf(p.22) が「トラップ系は統計が難しい→一様系（＝06）で
  統計をとる」と明記。**干渉（07）は物理的実証、統計は一様ソリトン格子（06）**。

出力（`figures/07_fourCondensate/`）は 06 と同じ一式＋`ground_state.png`（図A.2）。
