## 量子トンネル効果とは

古典力学では、エネルギー $E$ の粒子は高さ $V_0>E$ の壁を**絶対に越えられません**（坂を登りきれずに必ず戻る）。ところが量子力学では、波動関数が壁の中へ指数的に染み込み、壁が**有限の高さかつ有限の幅**なら反対側にわずかに漏れ出します。これが**トンネル効果**です。壁の中では波数が虚数 $\kappa=\sqrt{2(V_0-E)}/\sqrt{2D}$ になり、振幅が $e^{-\kappa x}$ で減衰しながらも 0 にはならないのがポイントです。

> 壁が**無限に高い**か**無限に厚い**とトンネルは起きません（完全反射）。「有限の高さ・有限の幅」の両方が必要です。

## 解く方程式と設定

相互作用を切った（$g=0$）線形シュレーディンガー方程式を 1 次元で解きます。

$$
i\,\frac{\partial\psi}{\partial t} = -D\,\partial_x^2\psi + V_\mathrm{ext}(x)\,\psi,
\qquad D=\tfrac12,\ g=0
$$

- **初期波束**：$\psi(x,0)=A\,e^{-(x-x_0)^2/4\sigma^2}\,e^{ik_0x}$（$x_0=-15,\ \sigma=2,\ k_0=1.5$）。右向きに運動量 $k_0$ を持つガウス波束。
- **群速度** $v=k_0=1.5$、**平均エネルギー** $E=k_0^2/2=1.125$（波束のエネルギー幅の上端でも $E_\max\approx1.5$）。
- **障壁**：$V_\mathrm{ext}=V_0=3.0$（$|x|<0.6$、幅 $L=1.2$）。$V_0$ を波束の最大エネルギーより十分高くとり、**全成分が古典的に透過不可＝純粋なトンネル**にしています。

初期条件は `0/Psire`・`0/Psiim` に `#codeStream` で解析生成、障壁は `0/Vext` に矩形ポテンシャルとして与えます。

```cpp
// 0/Vext : 矩形障壁  V = V0 for |x| < a, else 0
const scalar V0 = 3.0;   // barrier height (mean E = 1.125, E_max ~ 1.5) => pure tunneling
const scalar a  = 0.6;   // barrier half-width (width = 1.2)
forAll(V, i)
{
    const scalar x = mesh.C()[i].x();
    V[i] = (Foam::mag(x) < a) ? V0 : 0.0;
}
```

## 1次元メッシュの作り方

OpenFOAM は 3 次元ソルバなので、1 次元は「x を分割し、y・z を単一セルにして `empty` 境界にする」ことで表現します。今回は ParaView で帯状に見やすいよう、**y を 1 セルのまま幅 8 に拡幅**しています（物理は 1 次元のまま）。

```c
xmin -40; xmax 40;   // 領域 x∈[-40,40]
dy    8;             // 単一セルだが幅広に（表示用。物理は1D）
dz    0.2;           // 単一セル厚（empty 方向）
nx   400;            // dx = 80/400 = 0.2
blocks ( hex (0 1 2 3 4 5 6 7) ($nx 1 1) simpleGrading (1 1 1) );
// left/right: patch,  emptyY: empty,  frontAndBack: empty
```

x 両端は `fixedValue 0`（遠方の壁。計算時間内に波束が到達しない広さ）。realTime（Crank–Nicolson＋Picard 反復 `nCorrectors 4`）、$\Delta t=0.01$、$t\le22$ で解きます。

## 結果：4.2% が透過

波束が障壁に当たると、**大部分が反射**して入射波と干渉し（左側の縞模様）、**一部が障壁をすり抜けて右側へ透過**します。これが量子トンネル効果です。

最終時刻 $t=22$ で密度を左右に積分した透過率は **$T\approx0.042$（透過 4.2%）／$R\approx0.958$（反射 95.8%）**。矩形障壁の平面波厳密解

$$
T=\left[1+\frac{V_0^2\sinh^2(\kappa L)}{4E(V_0-E)}\right]^{-1},\qquad
\kappa=\sqrt{2(V_0-E)}\approx1.94
$$

からの理論値 $T_\text{exact}\approx0.035$ とよく一致しました。「大部分は跳ね返るが、数 % だけ壁を抜ける」という、いかにもトンネル効果らしい振る舞いです。計算中ノルムは一定（$=1.6$＝断面積 $8\times0.2$ ×規格化 $\int|\psi|^2dx=1$）で、安定に解けています。

> $e^{-2\kappa L}$ の粗い近似は薄い障壁では過小評価になるので使いません。今回は平面波の厳密解と直接比較しています。

## 補足：障壁を無限大にしたいとき

「完全な壁」を作りたいときに、巨大な $V_0$ を入れるのは**誤り**です。ポテンシャル項が硬直（stiff）化して $\Delta t$ を極端に小さくしないと破綻します。無限の壁はその位置で $\psi=0$ に固定する**ディリクレ境界（`fixedValue 0`）** で表すのが正しく、これが完全反射に対応します。今回の x 両端の `fixedValue 0` は、まさに無限の壁として働いています。
