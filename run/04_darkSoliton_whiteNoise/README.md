# 04_darkSoliton_whiteNoise — カマキリ流（白色ノイズ種）ダークソリトン崩壊

## 何の計算か
case 01 との違いを見るための計算。**まっすぐな（摂動なしの）ダークソリトン対**に
**白色ノイズ**を加えて実時間発展させる（＝カマキリ Fortran と同じ種の入れ方）。
全波長が励起され、最速成長モードが勝つので、**不規則・乱流的**な渦崩壊を狙う。

## なぜノイズが要るのか
まっすぐで清浄なダークソリトンは「**不安定だが定常**」な厳密解。摂動（種）がないと
snake instability は育たず崩壊しない。カマキリは白色ノイズで、case 01 は決定論的 cos 摂動で
種付けしていた。本ケースはカマキリ方式を採用。

## 仕様
| 項目 | 値 |
|---|---|
| モード | `realTime`（Crank–Nicolson + Picard 4反復） |
| 係数 | $D=0.5,\ g=1$ |
| 領域/格子/境界 | $[-16,16]^2$ / 128² / cyclic |
| 時間刻み・終了 | $\Delta t=0.005$、$t=150$（writeInterval 2 → 75フレーム） |
| 初期条件 | $\psi_0=\tanh\frac{x+x_0}{w}\tanh\frac{x-x_0}{w}$（**まっすぐ**, $w{=}1,x_0{=}6$）＋白色ノイズ |
| ノイズ | 加法的複素ノイズ 振幅 $n_o=10^{-2}$（実部・虚部を独立乱数 `Random` で、固定シードで再現可） |

※カマキリは $n_o=10^{-4}$。本ケースは時間短縮のため $10^{-2}$ に増やしている（成長が速い）。

## 実行
```bash
openfoam2512 -c 'blockMesh && schrodingerFoam'
```

## 期待される結果
- 序盤：まっすぐな2縞。ノイズが snake モードを励起。
- 中盤：縞が不規則に波打ち、点渦へピンチオフ。
- 終盤：多数の渦が動き回る乱流的状態（カマキリの後期に対応）。
- 図：`figures/04_darkSoliton_whiteNoise/density.gif`

## 計算結果

- $t=150$（30,000ステップ）まで完走。最終ノルムは 223.99894。
- 白色ノイズから横方向不安定性が成長し、2本のソリトン縞が崩壊して多数の低密度渦核が生成された。
