# dft01_hydrogen — 水素原子（Kohn–Sham DFT・M1）

`ksdftFoam` の最初の検証ケース。**電子1個の水素原子**を、原子単位（長さ=Bohr、
エネルギー=Hartree）で解く。M1 なので Hartree も交換相関も無し＝ただの
「核のCoulombポテンシャル中の1電子シュレーディンガー方程式」。

## 解いている式

    [ -1/2 ∇² + Vext ] ψ = ε ψ ,   Vext = -Z/√(r²+a²)   (Z=1, a=0.4)

を**虚時間発展**（後退Euler＋毎ステップ規格化 ∫ψ²dV=1）で基底状態に緩和する。
`-Z/r` の特異点は格子で表現できないため**ソフトCoulomb**（a=0.4）で丸める。

## 設定

- 領域 [-12,12]³ Bohr、64³ 一様メッシュ（dx=0.375）、境界 ψ=0。
- Δτ=0.1、収束判定 |Δε|<1e-8（τ≈21 で収束、211ステップ）。
- 初期値：ガウシアン（虚時間が 1s に整える）。

## 結果（検証）

| | ε [Ha] |
|---|---|
| ksdftFoam（このケース） | **-0.38388** |
| 厳密参照（径方向1D固有値ソルバ、同じ a=0.4） | -0.380872 |
| （参考）純Coulomb a→0 の厳密値 | -0.5 |

差 0.003 Ha（0.8%）は離散化誤差（96³ で縮むことを確認）。ソフト化 a=0.4 のぶん
-0.5 から浅くなるのは想定どおりで、a→0 外挿または擬ポテンシャル（M5）で扱う。
