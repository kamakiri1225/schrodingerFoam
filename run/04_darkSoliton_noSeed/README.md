# 04_darkSoliton_noSeed — 摂動なしダークソリトン対（対照実験）

## 目的

`04_darkSoliton_whiteNoise` の対照ケース。まっすぐなダークソリトン対に横方向摂動も
白色ノイズも与えず、snake instability が成長するためには種が必要であることを確認する。

## 仕様

| 項目 | 値 |
|---|---|
| モード | `realTime`（Crank–Nicolson + Picard 4反復） |
| 係数 | $D=0.5,\ g=1$ |
| 領域/格子/境界 | $[-16,16]^2$ / 128² / cyclic |
| 時間刻み・終了 | $\Delta t=0.005$、$t=150$（writeInterval 2） |
| 初期実部 | $\tanh((x+x_0)/w)\tanh((x-x_0)/w)$（$w=1,x_0=6$） |
| 初期虚部 | 0 |
| 摂動 | なし |

## 実行

```bash
openfoam2512 -c 'blockMesh && schrodingerFoam'
```

完全な並進対称性が数値的にも保たれる限り、縞は横方向に波打たず、渦へ崩壊しないことが
期待される。解析形が離散系の厳密な定常解ではないため、縞の幅や位相には一様な過渡応答が
生じうるが、それは snake instability とは区別する。

## 結果

- 30,000ステップを完走し、ノルムは初期・最終とも 224。
- $t=150$ でも2本の密度溝は直線のまま。固定 $x$ における密度の $y$ 方向レンジは 0。
- 最終密度範囲は $0.01575\leq|\psi|^2\leq1.00213$。横方向の波打ち・渦生成なし。
- 密度アニメーション: `figures/04_darkSoliton_noSeed/density.gif`

したがって、白色ノイズケースで現れる崩壊は離散化が自発的に作るものではなく、横方向の
不安定モードを励起する摂動（seed）によって開始されることを確認できた。
