# 03_vortexDipole_realTime — 「走る」渦対（渦-反渦ダイポール）

## 何の計算か
**渦対が並進する（走る）**ことを示すデモ。位相を刷り込んだ渦(+1)‑反渦(‑1)ダイポールを
一様背景に置き、実時間で発展させる。ダイポールは自己推進し、周期境界の箱を横切って「走る」。
→ 「case 01 では渦が走らないのに、なぜ？」への回答用（理由は下記）。

## 仕様
| 項目 | 値 |
|---|---|
| モード | `realTime`（Crank–Nicolson + Picard 4反復） |
| 係数 | $D=0.5,\ g=1$（$n_0=1,\ \xi=0.707$） |
| 領域 | $[-16,16]^2$、格子 128×128、境界 cyclic |
| 時間刻み | $\Delta t=0.005$、終了 $t=80$ |
| 初期条件 | 渦(+1)を $(0,+d)$、反渦(‑1)を $(0,-d)$ に位相刷り込み |
| 　振幅 | $a=\tanh(r_1/w)\tanh(r_2/w)$（コアの密度欠損）, $w=\sqrt2\,\xi$ |
| 　位相 | $\phi=\operatorname{atan2}(y-d,x)-\operatorname{atan2}(y+d,x)$ |
| 　分離 | $d=2.5$ |
| 　→ $\psi_{\rm re}=a\cos\phi,\ \psi_{\rm im}=a\sin\phi$ | |

## なぜ「走る」のか（case 01 との違い）
- **渦対（ダイポール）は非対称**：渦と反渦がずれて対になると、互いの誘導速度で
  対全体が**一定速度で並進**する（速度 $\sim (\hbar/m)/(2d)$、2つを結ぶ線と垂直方向）。
- case 01 は **静止ブラックソリトン＋左右対称な摂動** ＝ 正味の運動量ゼロ。
  生じる渦対も対称配置で相殺 → その場でくびれるだけで**走らない**。
- note記事（1次元・箱型初期条件）で窪みが「走る」のも同種：鋭いエッジ＝非平衡・
  局所位相勾配があり、グレーソリトンとして内側へ伝播するため。

## 背景の密度揺らぎ（縦縞）について
密度が縞状に激しく揺らぐのは **音波（フォノン）の放射**。位相刷り込みの初期状態は
GP方程式の厳密な定常解ではなく、コアの密度プロファイルが $\tanh(r/w)$ で近似的なため、
系が正しい形へ緩和する際に**余分なエネルギーを密度波として吐き出す**。周期境界で音波が
反射・周回して干渉し、背景がチラつく。渦対の並進そのものは正しい。

**低減策**：(1) 虚時間で軽く緩和してから実時間（統一ソルバの強み）、
(2) 正しい渦コア関数 $f(r)=r/\sqrt{r^2+2\xi^2}$ を使う、(3) 領域拡大／吸収境界。
